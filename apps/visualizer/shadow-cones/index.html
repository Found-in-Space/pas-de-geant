Why the shadow changes when distance changes
ru(x) = Rm − x(Rs − Rm) / Dsm rp(x) = Rm + x(Rs + Rm) / Dsm

Changing Dsm while keeping the radii changes both cone slopes. A uniform scale preserves the result; a non-uniform scale preserves it only when that same transform is applied to every surface.
