Geant integration cases

Start with the standard experience, then use the focused cases to inspect individual capabilities. Each page consumes the public package and owns its viewers. Earth viewers use Blue Marble imagery and measured elevation by default.

  • Standard experience — Blue Marble, measured terrain, TouchOS map, location detection, scale slider and VR.
  • Earth day and night — terminator, city lights and simulation time.
  • Earth landscapes journey — shared chapters, interruptible travel and free exploration.
  • Independent lifetimes
  • Optional sky backgrounds — no sky, Deep Star Maps image, or catalog stars.
  • Moon, Earth and Sun sizes — one size scale, authored spacing and VR head tracking.
  • Planner overlays — inspect terrain tile boundaries and imagery source tiles in the world viewer.
  • XR session and controls
  • Configured imagery and elevation
  • VoiceOS integration
  • Declarative embed
  • Tile planner — inspect the provider-independent quadtree cut without a renderer or network source.

Custom dataset checks and VoiceOS require a private config.local.json; their pages start with the default Earth surface. See the integration README for setup and manual acceptance steps.

Satellite and aircraft examples live in their respective projects.
